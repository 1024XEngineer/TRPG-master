## 第一组

记忆内容保存完整原文，模型请求仍由读取端控制预算。合法长对白的听众说明不再触发长度校验；单条异常不会丢弃已成功投影的其他记录，刷新失败仍可读取已有记忆。场景限定记忆保留 `scene_scoped`，只有明确的冻结受众可读取，空受众不能扩大为公开。

验证：`test_memory_integrity.py`、`test_memory_system.py`、`test_narration_npc_memory.py` 共 20 项通过；Ruff、格式和定向类型检查通过。历史上已经错误投影的记录由第四组的投影升级统一重建。

## 第二组

按公开事件类型表达随行、移动、持有、状态和信息变化，关联真实实体及行动者；结构化检定使用同一个正文投影供记忆与摘要读取。NPC 发言保留的听众也参与跨场景检索。旁白持久化只关联当前公开状态确认的随行者、实际说话者和行动角色，不从文本猜人物，不把所有场景 NPC 当作共同经历者。

验证覆盖：NPC 旁听后跨场景回忆、随行权威事件、检定到摘要，以及真实旁白持久化后的回忆。初次运行 30 项通过，1 项因旧测试省略事件类型失败；补齐事件 fixture 后该项通过。Ruff、格式和定向类型检查通过。

## 第三组

近期历史按行动关联玩家对白、NPC 回复和旁白，保留说话者、听众以及冻结受众，文本共同计入预算。步骤裁决通过既有记忆源读取 Keeper 上下文并保存到步骤输入，后续恢复可复用；规划与公开叙事仍使用玩家有权读取的记忆。读取故障回退为空上下文并记录日志。

验证：后端相关测试 124 项、框架契约及行动流程测试 87 项通过，包括对白权限、极小预算、跨场景回忆、步骤输入持久化和私密信息不进入公开规划 / 叙事。后端 Ruff 与定向类型检查通过；框架额外检查的基线限制见末节。

## 第四组

逐条记录已经处理的事件，包括没有可投影正文的来源，较早创建而较晚提交的事件也能增量补入。按房间锁定投影升级，旧版记忆从原始事件重建，恢复完整正文、人物关联及冻结受众。新增迁移 `j3k4l5m6n7o8`，不修改权威事件。

读取按来源版本过滤，规划、步骤裁决和叙事还传入当前行动标识，以玩家输入时间界定对白历史；当前行动的权威结果仍按世界版本读取。无法证明版本的旧数据仅用于最新视图。摘要也校验版本及时间边界，无法证明是历史快照的摘要不进入旧回合。

检索先按发生时间排序，同刻优先已确认事实；超预算的末条记忆返回首尾摘录及 `content_truncated`，完整正文继续留存。

验证：27 项记忆回归、32 项既有记忆与随行链路测试通过（两组包含重叠用例）；临时 SQLite 从基线升级到新迁移通过，Ruff 和定向类型检查通过。历史投影在部署迁移后第一次读取该房间时重建。


## 第五组

摘要输入保留说话者、听众、参与者、场景、来源版本及主张 / 旁白边界。首批事件内部发生换场景即可触发；NPC 跟进回复先持久化，再触发入队。摘要沿用现有模型适配器，没有新增叙事或 Agent 调用链。

新增逐来源消费进度：每次最多提交 4000 字正文，超长事件分段，保存成功才推进消费位置；已完成来源不再重复处理，晚提交的旧事件可以补入。来源进度、摘要和状态同事务保存，失败保留原进度。数据库原子领取支持 PostgreSQL 和 SQLite，过期租约可接管，运行中的旧工作者不能覆盖新租约。

后台启动及后续每 30 秒检查一页在场玩家，恢复漏排的任务；模型输出、旧摘要解析或数据库临时故障不会终止整个 worker。空任务释放租约；同一失败任务的轮询保留退避和次数上限，新事件或手动重建可重新触发。记忆读取、摘要入队 / 保存 / 恢复记录数量、版本、来源 ID 和错误类型，不记录完整提示词或私密正文。

新增迁移 `k4l5m6n7o8p9`。旧摘要标记为待升级，重新入队时按原始可见事件重建；升级完成前不将旧格式摘要交给消费者。

验证：摘要相关 23 项测试通过，覆盖人物归属、冻结受众、首次换场景、长文分段、晚提交、并发领取、生成期间新增回复、失败不消费原文、重试退避、过期租约、漏排恢复、空任务和坏摘要隔离。类型修正后重新运行新增 8 项测试，全部通过。旁白集成测试还验证 NPC 回复提交先于摘要入队。

## 部署与范围

运行更新代码前，在后端执行 `alembic upgrade head`，然后重启服务。记忆在房间第一次读取时自动重建；旧摘要由既有后台服务恢复并重建，不需要玩家重新开局。迁移和重建只改变派生数据，不改写世界状态或原始事件。

本次修复的是报告中的确定性数据链路问题。模型仍可能忽略已经提供的事实，摘要仍有长度预算。NPC 各自的知识隔离、由 Agent 主动选择上下文属于后续架构改动；当前继续区分 Keeper 的房间级读取与玩家有权读取的公开叙事输入。
