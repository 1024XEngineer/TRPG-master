# 开场自然改写：实施与真实模型复测

日期：2026-09-10。决策：采用作者原文＋同源关键事实提醒＋精简模型输入，允许自然改写；保留现有开场生成、一次重试及原文兜底。

## 修改内容

- 模组增加可选 `opening_key_facts`，从已有公开开场提取任务、关系、线索来源、数量/单位、时间和行动限制。非空清单必须有原文；旧版本缺省时序列化不增加空字段。清单供生成参考，不提交规则效果。
- 从会话绑定的同一模组版本读取原文和清单。提供方与输入长度日志统一使用 `to_prompt_dict()`；去掉内部 ID、空默认字段，有原文时去掉模组背景和单人履历。保留公开场景名称、描述、时间、非空现场细节及人物公开状态/身体限制。
- 提示词允许合并、重排、改写对白和略去重复修饰。单人第二人称开场不再强制点名；多人及 named_actor 仍要求身份和主体清楚。
- 移除整段原文逐字正则与对应的 source_coverage 重试要求。继续校验输出格式、空事实 ID/行动建议、协议残留、多人姓名与主体；仍最多重试一次，共用超时预算，失败后返回完整原文。
- **程序不自动验证语义完整性。** 清单是提醒；如果模型遗漏事实但通过结构/主体校验，当前不会因此自动重试。此次明确接受这一边界，避免重新建立逐句匹配规则或新增运行时审核模型。
- 发布声明升级为追书人 3.0.12、银之锁 3.0.4、幸福蛙蛙村 3.0.14，已有会话继续绑定旧版本。蛙蛙村继承此前 3.0.13 的地图/信息可见性修正；原文与事实清单未混入后续调查答案。

## 复测方式与对比限制

复用上轮四个案例：蛙蛙村单人/三人、追书人单人、银之锁单人；人物姓名、职业和原文相同。每个案例运行两次，共 8 次开场，轮次之间没有调整提示词。使用真实初始化、玩家视图投影、SessionViewApplication.generate_opening 和当前提供方适配器，所有房间仅存在于内存；未写入真实房间。

请求仍为官方 DeepSeek 接口的 deepseek-chat，默认采样、未设 seed、关闭 thinking。本轮 8 次响应的 model 字段均为 **deepseek-flash**，上轮则为 **deepseek-v4-flash**。返回标识不同且样本较少，不是严格控制变量的模型质量比较，不能把全部差异归因于代码，也不能据此估计线上遗漏概率。
