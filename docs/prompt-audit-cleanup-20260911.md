# 提示词检查与清理（2026-09-11）

检查基线：当前分支 `6b99b31`。已清理案例化提示、重复指令和相互矛盾的要求。
未发现全局提示词按“蛙蛙度假村”、具体挂画或某个 NPC 名称执行特殊逻辑；发现了历史回归案例和参考图特征长期留在通用提示词中。

## 检查范围

覆盖 10 个运行时提示词入口，包括实际拼接后的规划、裁决、叙事、开场、入口分流、NPC 对话、摘要、人物背景和生图提示词；同时检查引擎拒绝后的修正提示、输出 JSON Schema 描述、DeepSeek/Qwen 的协议包装，以及确定性生图提示词。

模组开场原文、场景事实和 NPC 专属美术资料属于内容输入，不是通用模型行为指令。解析文档中的字段说明与示例也不作为运行时系统提示词，因此保留。

## 发现与处理

| 问题 | 原因与修改 |
| --- | --- |
| 裁决规则整段重复 | `current_step_adjudication_instructions()` 与后端公共裁决指令重复携带旅行、物品取得、Runtime 创建、目标范围等规则，实际请求会叠加。步骤片段现在只交代本步职责和修复语义，公共规则只拼接一次；兼容主持片段也精简重复表述。 |
| 单次回归案例进入全局叙事 | 删除“我是退役军官”“拿起电话拨号 / 茶杯抿一口 / 手册翻页 / 传单端详”等固定示例，保留通用的主体归属、临时使用与正式取得的区别。局部提交历史可追溯到 `9bbcce8`（#309）、`884cb1f`（#512）。 |
| 固定时间与场景修辞 | 删除 `hour_18 / hour_20`、固定钟点/天数示例，以及反复罗列眼神、肩膀、手指等身体细节的禁令。保留离散时间逐点推进、仅使用公开时间、简洁旁白和必要感官限制。时点提示可追溯到 `3150823`。 |
| 根据缺少结果擅自推断失败原因 | 原提示把“无抵达结果”导向“没找到地点、仍在原处”，把“不在最终背包”导向“拿不动”。改为根据实际证据交代障碍、暂用、转交、放置、消耗或未完成取得。 |
| 分流指令互相冲突 | 同时要求返回 JSON 又笼统禁止 JSON；允许 `rule_once` 携带目标 ID 又禁止 ID；通用转交条款覆盖规则匹配条款。现在区分路由协议字段与玩家可见正文，并明确各路线的条件。 |
| 正常裁决与修复阶段目标范围不同 | 旧 `TARGET_UNAVAILABLE` 修复提示允许直接从 Keeper 全量实体/地点/信息词表选目标。现在与公共裁决约束一致：PlayerView 可作用目标，或匹配规则明确允许的目标，不把效果词表当成目标权限。规则未指定技能时仍可从角色已有技能中选择。 |
| 参考图人物特征污染通用生图提示 | 删除“金色卷发、绿色眼睛、绿色礼服、白色花饰、蜡烛、书架”等固定特征枚举，改为只借鉴画风、具体人物与环境依据角色资料。删除重复追加整段画风要求和重复自检清单；去掉无条件排除“科幻机甲”的时代预设。来源可追溯到 `667ee16`（#202）。 |
| Schema 描述夹带实现说明 | 时间效果 docstring 中的固定“中午睡到 20:00”示例会随 schema 发给模型，现改为通用逐点推进规则。规则引用描述去掉内部 issue 说明；状态申报描述去掉类型选型解释，将必要维护说明移到代码注释。字段、类型和校验逻辑不变。 |
| 测试固定整段提示词文案 | 原有部分测试要求相同规则在两个提示片段中都出现，反而锁死冗余。改为在实际模型适配器调用边界检查公共契约仅拼接一次、入口职责分开、候选上下文及规则/检定结果保留；既有引擎行为测试保留。 |

共享的主持裁决提示版本更新为 `trpg-host-intent-v10`。没有增加模型调用、执行分支或新的兜底流程。
